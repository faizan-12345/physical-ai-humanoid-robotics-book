### Edge Cases

- What happens when a user attempts to run code examples on incompatible hardware? (Book should clearly state minimum/recommended hardware).
- How does the RAG chatbot handle queries outside the scope of the book's content? (Should respond gracefully indicating it cannot answer or lacks information).
- What if the user tries to deploy the Docusaurus site without configuring GitHub Pages correctly? (Deployment instructions should anticipate common errors and provide troubleshooting).

## Requirements *(mandatory)*

### Functional Requirements

-   **FR-001**: The technical book MUST be structured as Docusaurus documentation.
-   **FR-002**: The book MUST include 4 major modules: ROS 2 fundamentals, Digital Twin, NVIDIA Isaac, and VLA.
-   **FR-003**: Each module MUST include diagrams, code examples, and workflows.
-   **FR-004**: The book MUST provide complete end-to-end Capstone project instructions for an autonomous humanoid robot simulation with conversational AI.
-   **FR-005**: The book MUST include a hardware requirements section covering Workstation, Edge Kits, and Robot Lab.
-   **FR-006**: The deployed book MUST integrate a RAG chatbot.
-   **FR-007**: The RAG chatbot MUST be able to answer questions based on the full book's knowledge.
-   **FR-008**: The RAG chatbot MUST be able to answer questions using only selected text from the book.
-   **FR-009**: All code blocks provided in the book MUST be tested and runnable.
-   **FR-010**: The book's content correctness MUST be verified against official documentation for ROS2, Gazebo, Unity, NVIDIA Isaac, OpenAI, Whisper, Qdrant, Neon, and GitHub Pages.
-   **FR-011**: Deployment instructions MUST be provided for Docusaurus to GitHub Pages.
-   **FR-012**: Deployment instructions MUST be provided for a RAG server using FastAPI.
-   **FR-013**: Deployment instructions MUST be provided for Qdrant Cloud (Free Tier).
-   **FR-014**: Deployment instructions MUST be provided for Neon Postgres (Free Tier).
-   **FR-015**: Deployment instructions MUST be provided for OpenAI Agents/ChatKit SDK.
-   **FR-016**: All examples in the book MUST be feasible with free or student-accessible hardware/software (Jetson, Gazebo, Isaac Sim).
-   **FR-017**: The book MUST avoid unnecessary robotics math unless required for understanding.
-   **FR-018**: The book MUST NOT make unrealistic hardware assumptions, focusing on real, purchasable kits.

### Key Entities *(include if feature involves data)*\n
-   **Book Content**: Represents the Docusaurus Markdown/MDX files, including text, code, diagrams, and examples.\n-   **RAG Chatbot**: The conversational AI system that processes queries and retrieves information from the book content.\n-   **Vector Database (Qdrant)**: Stores embeddings of book content for efficient retrieval by the RAG chatbot.\n-   **Relational Database (Neon Postgres)**: Stores metadata or conversational history for the RAG chatbot, if required for statefulness.\n-   **Simulation Environment (Gazebo, Unity, Isaac Sim)**: The virtual space where robot behaviors and VLA concepts are demonstrated.\n-   **Humanoid Robot Model**: The virtual representation of the humanoid robot used in simulations and the Capstone project.\n
